# Diseño de navegación

El diagrama de [wireframe-navegacion.svg](wireframe-navegacion.svg) documenta el flujo propuesto para el proyecto personal **Mi Gestor de Hábitos**.

- **Tabs:** Hoy, Progreso y Perfil.
- **Stack:** detalle de un hábito, con navegación de regreso.
- **Ruta dinámica:** `/habitos/[id]`, que carga el detalle según el identificador del hábito.
- **Modal:** formulario “Nuevo hábito”, para una creación rápida sin abandonar la pantalla actual.
